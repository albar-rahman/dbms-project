# Contributing to Student Information Management System (SIMS)

Thank you for your interest in contributing to **SIMS**!

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Clone your fork**:
   ``bash
   git clone https://github.com/albar-rahman/dbms-project.git
   cd dbms-project
   ``
3. **Create a Feature Branch**:
   ``bash
   git checkout -b feature/your-feature-name
   ``
4. **Make Changes**:
   - Adhere to relational database integrity constraints and SQL best practices.
   - Maintain UTF-8 encoding across all text and web files.
5. **Submit a Pull Request** against the main branch with a clear description of your changes.
